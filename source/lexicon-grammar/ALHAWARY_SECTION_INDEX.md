**Why this file exists.** §3 of the Intaliq 1 architecture requires *"the exact Alhawary subsection and printed page number for every Grammar Ledger entry"* and forbids citing only a chapter or using the PDF viewer's page number. The copy in the project is an image-only scan with **no text layer** — 421 characters across 421 pages. This index was recovered by OCR of the book's own table of contents and is the instrument every ledger row cites against.

The PDF number is recorded here only so a page can be found again.**

## How to use it

1. Find the structure's section in the table.
2. Cite **§ number + printed page** in the Grammar Ledger row. Never the PDF page; never the chapter alone.
3. Where a citation carries weight — a licensing decision, a dependency claim, a sequencing argument — **read the page before citing it.** Render it with `pdftoppm -f <printed+29> -l <printed+29> -r 200 -png` and OCR it. A table of contents tells you where a topic is discussed, not what it says.

**OCR caveat, recorded rather than buried.** Titles are OCR output. English is clean; Arabic glosses inside titles are **not reliable** — the scan renders Arabic poorly and the index shows it (`4 pall 2 egal` for ديپتوت, and similar). **Section numbers and page numbers are the load-bearing fields and were spot-checked; Arabic in a title is decoration and must not be quoted from this file.** Quote Arabic from the page image instead.
