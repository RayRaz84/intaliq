# Intaliq 1 — إِنْطَلِق

The source and the published site of **Intaliq 1**, a ten-unit comprehensible-input course in Modern Standard Arabic for ages 8–13. The site (GitHub Pages, `main`) is https://rayraz84.github.io/intaliq/.

- `index.html` / `404.html` (identical) — the Studio: student book, notebook and digital pathways per unit. **Generated** by the Text build; do not edit by hand.
- `teacher.html` — the teacher's page (SC-104), generated by the same build; never linked from the Studio.
- `assets/art/` — the accepted illustrations and their manifest (the build verifies every file against it).
- `source/` — everything authoritative: the engine and unit data (`source/pipeline/engine_core.js`), the Studio source, the build and release gate, the curriculum, lexicon and governance instruments. Start at `source/00_SOURCE_INDEX.md`.

Build and gate (see `source/pipeline/INTALIQ_DEPLOYMENT.md`):

```
INTALIQ_STUDIO_VERSION=<n> node source/pipeline/build_studio_art.cjs
python3 source/pipeline/verify_release.py . <n>
```

The decision register under `source/governance/` is an export; rulings are appended only in the project copy (SC-118).
